Legal Authority Graph (case ↔ statute, bipartite)

Each case links to the statutes it applies. PageRank / HITS / Louvain run directly on this graph — 56,596 nodes, 93,509 edges.

Node size ∝ authority. HITS ranks statute authority as Constitution → IPC → CrPC → CPC → Evidence Act (face validity). PageRank scores each case's authority; Louvain recovers 1,522 communities — criminal, civil, constitutional, tax, labour, land — with no supervision.
